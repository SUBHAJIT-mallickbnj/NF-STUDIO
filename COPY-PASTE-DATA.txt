HOW TO INPUT INTO DB-NORM:
─────────────────────────────────────────────────────────────────────────

1. Open http://localhost:5173

2. Under "TABLE NAME" field:
   └─ Copy table name from above

3. Under "COLUMNS" section:
   └─ Click "+" button multiple times
   └─ Enter each column name

4. Under "PRIMARY KEY" field:
   └─ Copy primary key from above

5. Under "FUNCTIONAL DEPENDENCIES (BCNF)" section:
   └─ Click "+" button for each dependency
   └─ Left side (LHS): Copy the source
   └─ Right side (RHS): Copy the target
   └─ Example: EmpID → EmpName
      → Left: EmpID
      → Right: EmpName

6. Click the "Analyze" or "Detect" button
   └─ It will show current Normal Form

7. Click "Normalize to 3NF" or "Normalize to BCNF"
   └─ It will show decomposed tables
