STEP 5: Add FUNCTIONAL DEPENDENCIES

ACTION: Look for "FUNCTIONAL DEPENDENCIES (BCNF)" section
        You should see boxes for LHS and RHS with a "+" button

FIRST DEPENDENCY (EmpID → EmpName):
  1. Click the "+" button
  2. Left side (LHS): Type "EmpID"
  3. Right side (RHS): Type "EmpName"
  4. Click "+" to confirm or move to next

SECOND DEPENDENCY (EmpID → DeptID):
  1. Click the "+" button
  2. Left side (LHS): Type "EmpID"
  3. Right side (RHS): Type "DeptID"

THIRD DEPENDENCY (DeptID → DeptName):
  1. Click the "+" button
  2. Left side (LHS): Type "DeptID"
  3. Right side (RHS): Type "DeptName"

FOURTH DEPENDENCY (DeptID → Location):
  1. Click the "+" button
  2. Left side (LHS): Type "DeptID"
  3. Right side (RHS): Type "Location"

RESULT: You should see 4 functional dependencies:
        ✓ EmpID → EmpName
        ✓ EmpID → DeptID
        ✓ DeptID → DeptName
        ✓ DeptID → Location

TROUBLESHOOTING:
─────────────────────────────────────────────────────────────────────────

Problem: Shows "1NF" instead of "2NF"
  → Make sure you added ALL functional dependencies
  → Check spelling of column names

Problem: Shows "3NF" instead of "2NF"
  → You might have entered dependencies wrong
  → Double-check LHS and RHS directions

Problem: Creates 1 table instead of 2
  → The normalization might not be working
  → Try normalizing to BCNF instead

Problem: Creates 3 or 4 tables
  → You might have extra dependencies
  → Verify you added exactly 4 dependencies

Problem: Can't find buttons
  → Scroll down on the page
  → The buttons might be below the fold
